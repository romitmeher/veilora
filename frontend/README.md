# Veilora desktop frontend

React and TypeScript, hosted by Wails. Run `npm ci` here, then `wails dev` from the repository root to use the native backend. A standalone Vite preview does not supply native VPN or filtering functionality.

- `npm run build`: TypeScript and production assets.
- `npm run lint`: ESLint.
- `npm run fmt`: formatting check.

See the root [README](../README.md) for setup, screenshots, and validation limits.
